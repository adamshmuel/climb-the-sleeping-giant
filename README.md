# Climb the Sleeping Giant
A Roblox game built with [Rojo](https://github.com/rojo-rbx/rojo) 7.7.1.

## Getting Started
Install the tools and packages:

```bash
rokit install && wally install
```

Open `climb-the-sleeping-giant.rbxl` in Roblox Studio. It holds the world (the giant, the gardens and the meadow). Then start the Rojo server and click Connect in the Rojo plugin:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
