# Play jobs in this game

- Noise measure: wait until the meter is under 5 first. Keep watching 3 s after the player stands still and read the highest value (a thud counts only after 0.3 s at rest). A slip is a jump, and every jump thuds 20 times the zone's multiplier.
- A body over 20 studs from the test spot is SENT AWAY: log it, retry once, never count a fail. Split a rise into its parts (end of climb, landing) so a loud part can be named.
